사용 흐름
1. 앱 실행 → 모터 1~4 자동 연결 확인 → 저장된 휴식 자세로 이동
2. 시작 준비 창의 “휴식 자세로 이동” 버튼으로 필요 시 다시 이동하고, 작업 시작 위치로 이동
3. 화면 위치 조절 → 내 위치 기준 5초 저장 → 준비 완료
4. 기준 자세 측정 → 기존 센서 준비와 자세 보정 순서대로 진행
5. 자세 코칭 시작 → 측정 끝내기 → 기존 휴식 자세 이동 → 측정 기록
프로필 불러오기, 측정 종료 시의 모터 이동은 기존과 같습니다. 화면에서 미리 안내합니다.
연결 확인 버튼은 제거했습니다. 연결 또는 휴식 이동에 실패하면 장치 상세에서 원인을 확인하고, 장치/전원을 점검한 뒤 앱을 다시 실행하세요.
오른쪽 위 ×는 기존 closeEvent를 통해 카메라/작업 프로세스를 정상 종료합니다.
